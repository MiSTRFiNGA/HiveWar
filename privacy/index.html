HiVE War — Privacy Policy

Last updated: 2026-07-30 · Operator: MiSTRFiNGA / Empire Games

HiVE War is a single-player browser / mobile web game. It does not require an account and does not sell personal data.

Data we collect

None on our servers. The game stores progress and settings only on your device using browser or WebView localStorage (for example high scores, unlocks, or options). Meta upgrades and run progress use localStorage only; no account system ships in the APK shell.

Network

The web build is hosted on GitHub Pages. The Android shell may request the INTERNET permission so the WebView can load local packaged assets and, if used, standard platform SDKs on portal builds. We do not operate a separate analytics backend for this title.

Children

The game is intended as a general-audience arcade/puzzle experience. We do not knowingly collect personal information from children.

Contact

Questions: open an issue on github.com/MiSTRFiNGA/HiveWar or contact the developer via the GitHub profile.
